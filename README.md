# Linux Administration Projects (Access Control & System Management)

## Overview
This repository contains hands-on Linux administration projects focused on file permissions, ownership, and user/group management.

The goal is to build a strong foundation in system security, access control, and real-world Linux operations.

---

## Projects

### Project 1: File Permissions
- Learned how to manage file permissions using `chmod`
- Worked with numeric modes (e.g., 644, 700)
- Controlled read, write, and execute access for users

---

###  Project 2: File Ownership
- Used `chown` to assign ownership to users and groups
- Understood the difference between ownership and permissions
- Applied secure configurations (e.g., `chmod 600`) to protect files

---

### 🔹 Project 3: Users and Groups
- Created users and groups (`useradd`, `groupadd`)
- Managed group membership (`usermod -aG`)
- Implemented group-based access control
- Applied permissions (`chmod 770`) for secure collaboration

---

## Key Skills Demonstrated
- Linux file permission management (`chmod`)
- Ownership and access control (`chown`)
- User and group administration
- Role-based access control (RBAC)
- Basic Bash scripting

---

## Security Concepts
- Principle of least privilege
- Restricting access to sensitive files
- Using groups to manage permissions efficiently
- Preventing unauthorized access

## Conclusion
These projects demonstrate practical Linux administration skills focused on security and access control.
